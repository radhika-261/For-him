A LITTLE WORLD OF US ♡ — PERSONALIZED WEBSITE

Included:
- Dreamy pink theme, floating hearts and sparkles
- Secret question: “Hum pehli baar kis date ko mile the?”
- Accepted answers include 16 December, 16th December, 16/12 and 16-12
- The provided YouTube song embedded
- The Hinglish anniversary message supplied in chat
- All 7 uploaded photos placed in the gallery
- Responsive layout for phone and laptop

PREVIEW:
Open index.html in Chrome. Scroll to the secret question and enter “16 December”.

PHOTOS:
The photos are already in the photos folder. To replace any image, keep the same filename:
couple-1.jpg through couple-6.jpg, and hands.jpg.

PUBLISH:
1. Extract this ZIP.
2. Upload index.html and the photos folder to a GitHub repository.
3. In Netlify choose Add new site > Import an existing project, connect GitHub, and select the repository.
   Or use Netlify manual deploy with the extracted site folder.
4. Open the published link on a phone to test it.

PRIVACY NOTE:
The date answer is checked in front-end JavaScript. This is a fun surprise gate, not real security, because visitors can inspect the website code. Do not put confidential information in the site.
YouTube needs internet and may require the visitor to press Play. Some videos may not allow embedding.
